# Fabric Mod Template for 1.21.x (Client-side)

This is a lightweight template for creating **client-side Fabric** mods.

## Checklist

Before starting work on your project, make sure to follow the checklist below:

- [ ] `gradle.properties`
    - [ ] Change `maven_group`
    - [ ] Change `archives_base_name`


- [ ] `test.mixins.json`
    - [ ] Change `package`
    - [ ] Rename the file itself


- [ ] `fabric.mod.json`
    - [ ] Change `id`
    - [ ] Change `name`
    - [ ] Add `description`
    - [ ] Change `authors`
    - [ ] Add `contact`
    - [ ] Change `icon`
    - [ ] Change `entrypoints`
    - [ ] Change `mixins`


- [ ] `src/main/java`
    - [ ] Rename packages


- [ ] `src/main/resources`
    - [ ] Rename directories
    - [ ] Change icon
    - [ ] Change translations


- [ ] `TestConfig.java`
    - [ ] Rename the file itself


- [ ] `YACLIntegration.java`
    - [ ] Rename `TestConfig` class occurrences


- [ ] `Helper.java`
    - [ ] Rename the file itself
